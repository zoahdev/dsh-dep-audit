# Security Policy

Dependency supply-chain hygiene audit for DeepSeek Harness for DeepSeek Harness (dsh).

## Reporting a Vulnerability

Please open a private security advisory on GitHub (Security -> Report a vulnerability) rather than a public issue. Include:

- the plugin version and dsh version
- a minimal reproduction
- the impact if known

## Supported versions

Only the latest npm release receives security fixes.

## Disclosure

We aim to acknowledge reports within 48 hours and ship a fix as a patch release.
